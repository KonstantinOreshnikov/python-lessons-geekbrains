# Practice Kata / Практическая задача

## English

Implement and extend a daily activity scorer. Each activity has planned and actual minutes plus a completion flag. The scorer must validate inputs, calculate a bounded score and summarize a day without mutating the input collection.

Run the tests with `python -m pytest`. Then add tests for zero planned minutes, scores above 100%, an empty day and invalid negative values.

## Русский

Реализуйте и расширьте расчёт оценки ежедневной активности. У каждой активности есть плановые и фактические минуты и признак выполнения. Расчёт должен проверять входы, ограничивать score и формировать итог дня без изменения исходной коллекции.

Запустите тесты командой `python -m pytest`. Затем добавьте тесты для нулевого плана, результата выше 100%, пустого дня и отрицательных значений.
